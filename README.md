# AskAH + AskQuest (WoW Forever addons)

**Current:** AskAH 0.14.0 · AskQuest 0.7.3

## Download
**[AskAH-AskQuest.zip](https://github.com/pwoo32/askah-feed/raw/refs/heads/addons/AskAH-AskQuest.zip)** (always the newest)

## Install on any PC
1. Close WoW. Download the zip above.
2. Unzip it and copy the `AskAH` and `AskQuest` folders into `<your WoW folder>\_forever_\Interface\AddOns\` (replace old copies).
3. Optional, to keep auction prices updating: double-click `AddOns\AskAH\Feed\Install-Sync.cmd` once. Then `/reload` in game to load new prices.

Full steps, including the optional "did my auction sell?" tracking: [AskAH/INSTALL.txt](AskAH/INSTALL.txt).

## Update
Download the zip again and copy the two folders over. Your settings are kept (WoW stores them separately).

The folders in this branch are the same files as the zip, if you'd rather browse them.
